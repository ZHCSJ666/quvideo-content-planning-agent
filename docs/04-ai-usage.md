# AI 辅助范围与个人贡献

## 已发生的工作

候选人在讨论中提出并确认业务场景：跨境电商、多语言营销内容、德国/美国各两条、完整方案而非成片；明确要求真实 Agent 决策、异常处理、阶段验收；选择 LangGraph + LangChain、CLI + 结构化 Trace 和轻量 Streamlit。确认采用合成资料、全过程模拟成本、模拟时钟和失败续跑。

Codex 根据这些决策编写代码、合成数据与 SVG 素材、测试、运行脚本和项目文档，并调用用户授权的模型接口执行验证。文档中的代码实现和运行分析属于 AI 辅助产出，不应冒充全部由候选人手写。模型运行的业务规划/脚本/语义审核由配置的服务模型生成；每份 Trace 标识 live 或 offline。

## 验证方式

阶段性自动测试用于验证约束、成本、状态、幂等、恢复。离线策略固定可复现，不能证明模型决策。真实 API 案例用于观察工具调用、错误后的修正和实际多语言内容。所有结果引用 `examples/`；未通过或未验证部分在评估文档中说明。

## 个人复核待记录

截至本文件首次生成，尚未记录候选人对具体实现的人工代码修改或母语内容审核。提交前应如实补充：实际审阅/修改的文件、修改原因、自己复跑的命令及结果、对状态图和重规划案例的解释。不要将 AI 执行的测试填写为本人手动验证。

## 数据与凭据

只把合成商品和市场资料发送给模型。外部 API 凭据从环境变量或仓库外配置读取；仓库不包含密钥、原始试题或个人隐私。没有把整份试题上传到模型，也没有使用真实客户素材。
