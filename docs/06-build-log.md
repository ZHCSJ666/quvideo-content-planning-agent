## 实际观察与修改

- 真实模型初次用中文描述检索英文标签时没有命中；模型曾尝试用 US 素材制作 DE 方案，被市场约束拒绝。随后模型改用正确查询和素材。增加空检索的可用标签与恢复提示，不把空结果伪装为有素材。
- 真实模型审核识别出德语脚本将不锈钢杯误称玻璃杯、旋盖描述暗示未证实防漏；产物标记 rejected，费用保留，等待模型修复。
- 发现一次真实模型审核请求超时，记录为 TOOL_ERROR 而非成功。提供可选 vLLM 非思考模式配置以降低运行延迟，兼容性已用真实请求验证；后续效果以完整案例为准。
- 加测真实磁盘写入失败、跨进程恢复、部分补充约束、等待时间耗尽、模型不可用和失效依赖，累计 35 项通过。

- CLI 实际运行完成离线四条方案，导出文件与账本一致；随后实现复用同一 Service 的界面，AppTest 验证归档查看和新建任务均通过。界面完成后真实模型端到端回归继续串行运行。
- 三条早期并行探索运行由操作者主动中止并归档在 `examples/exploratory/`，不作为最终成功案例；保留检索不匹配、审核拒绝与真实超时证据。

- 对首条工程完成案例做二次内容核查，发现同源模型审核放过了轻量、耐用、环保与文化偏好推断。将历史案例连同二次核查结论移入 `examples/exploratory/`；增加事实约束回归测试、区分面向用户文案与否定说明，收紧策略、生成和审核提示，重新执行最终真实验收。该检查由 Codex 完成，未冒充母语人工审核。

- 真正的故障验收又暴露了错误反馈丢失：计划修改使旧产物失效时，生成工具也失去先前审核意见，导致同类声明反复出现。将失败反馈独立于产物有效性保存，修复后增加回归测试（累计 41 项）。历史运行按调用/尝试上限如实返回未完成，没有伪造完成。

- 紧预算案例先由标准档改为经济档，后因内容返工使最低总费用升至 43，超过硬预算 40。保留已通过的 DE-1，不将部分成功当成完整交付。模型停止建议出现忽略沉没费用的口算，程序改为从账本生成最终缺口说明；保留原始建议并显式恢复验证。
- 检查并修复多文件保存顺序、零预算恢复默认值、导出目录遗留旧方案，以及缺约束时 Trace 为空的问题。对应回归验证覆盖已完成凭证、界面约束和导出文件，未用成功日志替换失败记录。
- Qwen3.8 故障探索出现真实 API 超时，随后模型反复尝试修改计划来重置尝试次数。程序一直拦截；操作者中止无进展的探索并保存原始结果。模型观察中补充尝试计数，错误反馈明确不可重试，测试验证改档位或策略不能绕过上限。
- 显式续跑采用先前已完成正常案例的 Qwen3.5 非思考配置，并将请求超时设为 120 秒。恢复事件、模型标识、原始费用与产物连续保留；最终结果见 `docs/03-evaluation.md`，不能称为无人工干预的自动恢复。
